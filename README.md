# Legacy — Coaching en ligne

Site vitrine du coaching de **Richard** : streetlifting, force athlétique et calisthénie.

Programmation personnalisée, suivi RPE, nutrition pilotée et progression mesurée.

## Stack
Site statique, sans dépendances : `index.html` + `styles.css` + `script.js`.

## Aperçu local
Ouvrir `index.html` dans un navigateur, ou lancer le mini-serveur PowerShell :

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
# puis ouvrir http://localhost:5510
```

## Hébergement
Déployé via GitHub Pages.
